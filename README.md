## About

I'm a Biomedical Engineering student and Python developer working on Machine Learning, Deep Learning and Computer Vision.

My work sits where **images and biological signals meet models**: I like taking a raw medical or scientific dataset, building a clean pipeline around it, and comparing approaches properly instead of trusting a single number. I'm currently deepening my computer vision skills with OpenCV, and I'm steering my path toward **bioinformatics and medical AI**.
